# Установка Fanstik-OS — план и критерии

> Документ описывает цель и будущие требования. Установщик, live-среда, форматирование дисков и установка системы пока не реализованы, если соответствующие пункты Roadmap не отмечены и не подтверждены тестами.

## Целевой сценарий
1. Скачать UEFI-only ISO и записать на USB.
2. Загрузить live-среду через UEFI.
3. Проверить базовое оборудование и, когда готово, сеть.
4. Запустить установщик.
5. Выбрать диск, увидеть модель/размер и разделы; подтвердить разрушительные операции явно.
6. Создать GPT, EFI System Partition (FAT32) и основной раздел с поддерживаемой FS.
7. Установить загрузчик, kernel, системные файлы и базовые приложения.
8. Настроить пользователя, имя устройства, язык, клавиатуру, часовой пояс.
9. Проверить результат установки, показать лог/ошибки и завершить.
10. Перезагрузиться с установленного диска и подтвердить boot установленной системы.

## Безопасность
- По умолчанию не форматировать и не удалять разделы.
- Предупреждать о потере данных и требовать явного подтверждения с отображением целевого диска.
- Проверять объём диска, разделы, filesystem, ошибки записи и загрузочные файлы.
- Установка должна завершаться с точным статусом, а не сообщать успех при ошибках.
- Разработать recovery/rollback насколько позволяет архитектура.
- Первые тесты проводить только на виртуальных дисках QEMU, не на пользовательских накопителях.

## Приёмочные тесты
- ISO загружается через UEFI в QEMU/OVMF.
- Установщик обнаруживает виртуальный диск и корректно отображает его.
- Виртуальный диск разбивается/форматируется согласно выбранной схеме с явным подтверждением.
- Установка проверяет и копирует необходимые компоненты.
- После reboot система загружается с виртуального установленного диска, не с live ISO.
- Тесты фиксируют serial logs и ошибки.
- Документация описывает только фактически проверенные сценарии.

## Предпочтительная начальная схема
- GPT.
- EFI System Partition (FAT32), достаточный размер согласно выбранным загрузочным компонентам.
- Основной раздел для FanstikFS, когда filesystem достигнет безопасного уровня; до этого допускается временный проверенный вариант для прототипирования.
- UEFI removable boot path остаётся `EFI/BOOT/BOOTX64.EFI`.
